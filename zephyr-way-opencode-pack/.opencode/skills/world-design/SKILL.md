description: Build Zephyr Way's stylized low-poly islands, terrain, airport, villages, vegetation, landmarks, roads and environmental composition.
---

Treat the world as an aerial composition, not a ground-level city simulator.

Prioritize:
- strong silhouettes
- readable landmarks
- useful navigation cues
- balanced foreground/midground/background density
- procedural/reusable components

Core world elements:
- ocean
- terrain
- coastline
- mountains
- valleys
- airport/runway
- villages
- buildings
- trees
- rocks
- landmarks
- boats/props

Prefer shared meshes, shared materials, instancing, visibility ranges and simple collision.

Use design JSON from `design/` as the source of high-level world intent when present.
