name: godot-core
description: Build and maintain Zephyr Way using Godot 4.7.x scenes, nodes, resources, signals, input, lifecycle, and typed GDScript.
---

Use this skill for general Godot implementation.

- Target Godot 4.7.x.
- Use typed GDScript where practical.
- Prefer composition over deep inheritance.
- Keep scenes modular.
- Use signals for decoupled communication.
- Use Resources for reusable structured data.
- Avoid unnecessary Autoloads.
- Keep scripts focused and reasonably small.
- Do not invent APIs; verify uncertain APIs against project/docs before using them.
- Preserve working systems and avoid unrelated refactors.
- Validate changed scenes/scripts after implementation.
